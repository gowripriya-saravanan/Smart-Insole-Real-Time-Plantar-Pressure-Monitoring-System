# Smart-Insole-Real-Time-Plantar-Pressure-Monitoring-System

# 🦶 Pressure-Guided CNC Bio-Composite Smart Insole

A smart insole system for real-time 8-zone plantar pressure monitoring using pressure sensors, ESP32, Bluetooth BLE, and a mobile/web dashboard.
https://smartinsole-upqzgndk.manus.space

### Key Features
- 8-Zone Pressure Monitoring
- Real-Time Pressure Visualization
- Bluetooth BLE Connectivity
- High-Pressure Alerts
- Personalized Pressure Analysis
- CNC-Based Support Design
- Bio-Composite Insole Development

### Technology
ESP32 • Pressure Sensors • BLE • React • TypeScript • Vite • CNC
